05 / ENGINEERING CHOICES

Designed to inspect.
Built to reproduce.

Evidence you can trace

Findings cite participant-visible evidence IDs. Input fingerprints identify the files used.

Policy-aware treatment

Retained records stay available. Tombstones preserve stable references while removing prohibited identifiers.

Bounded execution

SQL snapshots run in an isolated in-memory database with restricted operations. Audits propose actions; they do not delete live data.

Local inference

The recorded final run used local OCR and PDF extraction, with zero cloud LLM calls and $0 external API cost.

A hybrid foundation: local multimodal extraction for business artifacts, deterministic rules for consistent output, and optional advisory AI review.
